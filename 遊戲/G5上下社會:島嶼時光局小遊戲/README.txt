島嶼時光局 v17.5｜靜態部署包

遊戲：臺灣歷史探索 RPG、歷史複習與500張歷史記憶卡。
適合年級：以國小五年級社會課程範圍設計，也適合國小高年級複習。
時代／關卡：6個時代，共77個故事單元。
史前4（序章＋3章）、大航海4個主線階段、鄭氏6章、清領16章、日治21章、戰後26章。
大航海另含6份歷史知識委託；各時代另有總複習、手帳與知識活動。

部署
1. 將本ZIP完整解壓到網站任意子資料夾，讓 index.html 位於該資料夾根目錄。
2. 透過 https://你的網站/子資料夾/ 開啟。保留所有 .js、game.css 與 assets 的相對位置。
3. 不需要 npm、Vite、Node.js、資料庫、API或 chatgpt.site。此專案原本是直接執行的靜態頁，沒有 Vite 建置流程；資源均使用相對路徑。
4. 請用 HTTP/HTTPS 靜態網站預覽；直接雙擊 file:// 不是正式部署方式，各瀏覽器對本機檔案存檔的限制不同。
5. 音樂、音效以 Web Audio 即時合成，不需要外部音效服務。首次互動並開啟音樂後播放。
6. 「給老師的說明」保留官方史料外部連結；連結供自選查閱，遊戲執行不會向它們要求資料。

存檔
所有 localStorage 讀寫集中在 save-storage.js 的 SaveStorage.read/write/remove；JSON匯出／匯入的序列化集中於 SaveStorage.serialize/parse。
完整欄位說明見 SAVE-DATA.txt。設定可匯出、匯入JSON存檔。
存檔屬於目前網站來源（協定＋網域＋連接埠）及目前瀏覽器，沒有跨裝置自動同步。
從原網站搬到新網域，先在原網站設定匯出，再到新網站匯入。清除瀏覽資料會刪除本機進度。
同一網域下不同資料夾預設共用相同遊戲存檔鍵；若要隔離多份遊戲，請在 save-storage.js 為 key 統一加上不同前綴（舊進度先匯出）。

檔案
index.html：遊戲入口
*.js、game.css：瀏覽器執行程式與合併樣式（靜態網頁運作必備）
save-storage.js：集中存檔I/O
assets/：場景、人物、卡片等遊戲圖片
此包不含專案原始目錄、測試、node_modules、.env、Git資料或部署憑證。
